# Trading Conventions

## Report Standards
All market analysis reports must include:
1. Ticker / asset identification
2. Current price and % change
3. Technical setup (support/resistance, key indicators)
4. Fundamental summary (if equity)
5. Sentiment score (bullish/bearish/neutral with confidence)
6. Risk factors (minimum 2)
7. Recommended action with confidence level
8. Data source attribution with timestamps

## Data Standards
- Always cross-reference at least 2 data sources for any claim
- Prefer real-time data over cached/stale data
- Timestamp all data points with source attribution
- Note when data may be delayed (e.g., "15-min delay")

## Notation
- Prices in USD unless explicitly specified otherwise
- Percentages to 2 decimal places (e.g., +3.45%)
- Dates in ISO 8601: YYYY-MM-DD
- Times in ET (Eastern Time) for US markets
- Large numbers with comma separators (e.g., 1,234,567)
- Basis points noted as "bps" (e.g., +25 bps)

## Confidence Levels
- **HIGH:** 3+ confirming signals, no major contradictions
- **MEDIUM:** 2 confirming signals, minor headwinds
- **LOW:** Mixed signals or insufficient data
